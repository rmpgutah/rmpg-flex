# Code of Conduct

## Our standards

RMPG Flex is built by a small, professional team operating in a public-safety
context. We hold ourselves to the same standards of conduct that apply on
patrol, in dispatch, and in court:

- **Be respectful.** Disagreements happen — disagree about the work, not the
  person. No personal attacks, harassment, discrimination, or demeaning
  language, in code, commits, comments, PR reviews, chat, or any other forum
  tied to this project.
- **Be honest about scope.** If a change is bigger than the ticket, say so. If
  you broke something, say so. If you don't know, say so. Silent partial
  implementations and over-confident merges cost more than admitting a gap.
- **Protect sensitive data.** This codebase touches criminal-justice
  information, PII, body-cam / dashcam footage, jail rosters, warrants, and
  evidence custody. Treat every commit, screenshot, log, and bug report as if
  it could include sensitive data — because it can. Redact before sharing.
- **Credit work accurately.** Co-author tags on commits, attribution in PR
  descriptions, and honest mention of AI assistance where it applies.
- **Keep production safe.** Follow [`CONTRIBUTING.md`](CONTRIBUTING.md). No
  direct pushes to `main`, no `--no-verify` past `pre-push`, no skipping
  schema-migration verification. The discipline isn't bureaucracy — there are
  real officers and dispatchers on the other end of these changes.

## Unacceptable behavior

- Harassment, threats, or discriminatory language of any kind.
- Sharing sensitive case data, PII, or law-enforcement records outside the
  authorized scope of your engagement with RMPG.
- Sustained disruption of code review, releases, or operations.
- Retaliation against anyone for raising a conduct concern in good faith.

## Scope

This Code applies to all spaces tied to RMPG Flex — this repository, internal
chat, video calls, in-person meetings, and any external venue where you are
representing the project.

## Reporting

If you experience or witness conduct that violates this policy, report it to:

- **Christopher Zamora** (operator-owner) — chzamo@rmpgutah.us

Reports will be reviewed promptly and confidentially. Retaliation against
anyone who reports in good faith is itself a violation of this policy.

## Enforcement

Project maintainers may, at their discretion:

1. Issue a private written warning.
2. Require a public or private apology.
3. Revoke commit / review / repo access, temporarily or permanently.
4. Terminate the contributor's engagement with RMPG for serious or repeated
   violations, consistent with applicable employment and contractor agreements.
