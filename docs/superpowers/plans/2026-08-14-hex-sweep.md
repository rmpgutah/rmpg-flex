# Hex Sweep Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace all 4,078 in-scope hardcoded hex literals in `client/src/` with CSS-variable-backed Tailwind tokens so every surface re-themes automatically.

**Architecture:** 22+ sequential PRs, each covering one directory group. Every PR follows the same workflow: audit → read each file in context → assign role → substitute token → full vitest suite → commit → merge. No automation — substitution is always by role, never by find-and-replace.

**Tech Stack:** React 18 + TypeScript + Tailwind CSS + CSS custom properties (`theme-palettes.css`). Audit tooling: `client/scripts/audit-hex.mjs`, `client/src/utils/hexClassifier.ts`.

## Global Constraints

- **Never substitute excluded files** — PDF generators, Mapbox paint modules, `.tactical-dark` fixed values, categorical palettes (`connectionsGraphStyle.ts`, `geographyLabels.ts`), test fixtures, audit tooling. `hexClassifier.ts` is the authority.
- **Role map, not find-and-replace** — the same hex in the same file can have two different roles (e.g. page background vs recessed input). Read the JSX context before assigning a token.
- **Full vitest suite required before every commit** — `cd client && npx vitest run`. Targeted runs miss cross-file ratchet failures.
- **Every token must be in `tailwind.config.js`** — verify a new token appears in `dist/assets/*.css` before trusting it. `bg-surface-hover` is a known example of a token used widely that emitted no CSS because `hover` wasn't a configured scale key.
- **Gold only via vars** — `--field-label-color` (field labels) and `--panel-header-color` (section/panel headers) are the only two gold roles. Never write `text-accent-gold-*` directly in a component.
- **Numeric metric values → `text-rmpg-100`**, not gold.
- **Nothing color-valued in `client/src/index.css`** — colors there are theme-invariant.
- **Branch naming:** `claude/hex-sweep-<slug>` off current `main`.
- **Commit message format:** `fix(theme): hex sweep — <scope>`

### Inline style fallback
When a hex appears in a `style={{ color: '#...' }}` or `style={{ background: '#...' }}`, replace with the CSS variable directly:
```tsx
// Before
style={{ color: '#8fa3b8' }}
// After
style={{ color: 'var(--text-muted)' }}
```
